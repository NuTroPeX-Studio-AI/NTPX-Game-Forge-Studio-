## Increment

Upgrades `RustParserAdapter` from the verified B000022 lexical parser foundation to an AST-grade Rust syntax parser backed by `syn`. The adapter parses the entire Rust source file before emitting deterministic top-level evidence for functions, structs, enums, traits, modules, impl blocks, type aliases, constants, and statics. Source-line evidence comes from parser spans, stable ordinal ordering is preserved, and SHA-256 correlation evidence remains deterministic.

This removes the earlier brace-counting limitation for comments and strings and supports ordinary multiline/generic/attributed Rust item syntax without promoting nested methods into top-level evidence.
